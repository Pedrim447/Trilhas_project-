🛍️ Minha Loja Virtual

Projeto acadêmico desenvolvido por Pedro Cabral, como atividade da trilha de desenvolvimento web.

📌 Sobre o projeto

O projeto consiste no desenvolvimento de uma loja virtual, com o objetivo de apresentar produtos de forma organizada e atrativa, permitindo que os visitantes conheçam os itens disponíveis e seus respectivos preços.

A proposta é criar uma experiência simples, intuitiva e agradável para os usuários, aplicando os conhecimentos adquiridos durante a trilha de estudos.
